新生请说不：完整项目文件

现在试玩：
如果你拿到了单独的“新生请说不-单文件试玩.html”，用浏览器直接打开即可。
HTML 中已经包含角色、地图、音乐和音效，不需要联网登录。
此版本是本机排行榜，不同设备不会互通；浏览器禁止本地保存时会显示“仅本次页面有效”。

使用项目源码试玩：
电脑已安装 Node.js 时，解压整个项目，然后双击“本地试玩.cmd”。
浏览器会打开游戏。试玩期间保留启动窗口，关闭启动窗口会停止本地预览。

以后上传 GitHub：
1. 在你的账号下新建公开仓库 freshman-card-defence。
2. 上传解压后的文件与文件夹，保留目录结构。上传的是里面的文件，不是 ZIP 压缩包。
3. 仓库 Settings → Pages → Deploy from a branch。
4. 分支选择 main，目录选择 /docs，点击 Save。
5. 等 GitHub Pages 发布完成，使用它显示的网页地址。

修改：
修改 public/ 中的素材或代码，再运行 npm run build 更新 docs/，把源码与 docs/ 一起上传。
运行 npm run export 可以重新生成单文件试玩版，文件位于 release/。

worker/ 和 migrations/ 保留了共享排行榜的服务器源码，需要另外部署；GitHub Pages 不会执行它们。
源码、音频来源和操作规则见 README.md。
包内不包含登录凭据、Cloudflare 账号配置或测试成绩。
